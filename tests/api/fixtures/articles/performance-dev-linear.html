How's Linear so fast? A technical breakdown

Dennis Brotzky

Linear feels immediate because the interface treats local application state as the starting point and lets synchronization happen outside the critical path. Views can appear with useful data, updates can be reflected optimistically, and slower network confirmation can settle after the user has already moved to the next action.

The same principle applies to test design. A deterministic extraction test should keep article markup close to the target page while avoiding a fresh internet request on every run. The slower fetch boundary can still be covered by a small smoke check, but parser behavior belongs in fast fixture-backed tests.
